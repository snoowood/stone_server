# T1-01 — Go 프로젝트 초기화

## 의도

모든 코드 작업의 기반이 되는 Go 모듈 구조와 빌드 환경을 잡는다.
이후 모든 Task는 여기서 확립된 디렉토리 구조와 빌드 파이프라인 위에서 진행된다.

## 작업 목표

- `go mod init` 으로 모듈 초기화 (`github.com/gensdeis/stone-server`)
- `00_overview.md` 기준 디렉토리 구조 생성
  - `cmd/server/main.go`
  - `internal/auth`, `internal/gacha`, `internal/player`, `internal/timeguard`, `internal/achievement`
  - `pkg/db`, `pkg/cache`
  - `migrations/`
- `Dockerfile` 작성 (멀티스테이지 빌드, 최종 이미지 alpine)
- `go build ./...` 성공 확인

## 선행 의존

- 없음 (시작점)

- T1-03: Docker Compose 구성
